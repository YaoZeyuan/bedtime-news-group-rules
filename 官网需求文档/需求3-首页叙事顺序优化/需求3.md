# 需求3: 首页叙事顺序优化

## 背景

当前官网首页更像规则档案站：首屏之后很快进入荣誉殿堂和赞助展示。对于完全不了解群聊的访问者来说，这个顺序不能快速回答“这是什么群”“讨论质量如何”“为什么值得关注或加入”。

本需求希望调整首页叙事顺序，让陌生访问者先理解群聊价值，再阅读规则与支持信息。

## 目标

1. 让访问者在首屏快速理解：这是一个睡前消息观众自发维护的非官方高质量讨论群规则站。
2. 让访问者先看到群聊讨论的实际气质：高信息密度、证据优先、AI 辅助、规则自治。
3. 让访问者在产生兴趣后，再阅读群规、释规、变更记录和荣誉殿堂。
4. 继续遵守“不公开入群方式”的既有边界。

## 推荐展示顺序

### 1. 首屏定位

首屏需要回答：

- 这是什么：睡前消息讨论群规则站（非官方）。
- 群聊价值：高信息密度、理性讨论、资料共享、AI 校准、规则自治。
- 访问者可以做什么：看讨论现场、理解讨论方式、查看群规。

首屏不应以赞助、荣誉殿堂或规则全文作为最主要信息。

### 2. 脱敏讨论现场

在首页靠前位置展示一组“讨论现场”摘要，用来让陌生访问者理解群聊内容质量。

展示要求：

- 可以参考 `群组文档/群聊梳理` 中的历史样例。
- 不直接展示原始聊天记录。
- 不展示真实发言人昵称。
- 不展示可反向定位个人身份的信息。
- 可以使用“群友甲 / 群友乙 / 管理员 / AI 判定”等泛化称呼。
- 内容以摘要、主题卡片、争议问题和讨论方式为主。

建议展示主题：

- AI 与产业现实：区分营销叙事和可验证行业信息。
- 社会政策讨论：围绕生育、教育、劳动制度等问题展开论证。
- 规则自治实践：AI 判定、Top3 警告、释规和版本化维护。
- 投资与长期判断：用历史回溯和模型校准减少情绪化判断。
- 日常互助：减肥、租房、工具使用等生活经验交流。

### 3. 为什么值得关注

在讨论现场之后，用较短模块说明群聊吸引力：

- 信息增量：讨论不追求热闹，追求可复用的信息和推理。
- 证据优先：争议观点需要数据、来源和逻辑链。
- AI 辅助：AI 用于校准概念、辅助审判和整理资料。
- 规则自治：群规、释规和变更记录公开维护。
- 生活感：宏大议题与普通生活经验并存。

### 4. 群组简介与群文化

在访问者已看过讨论现场后，再解释群组背景、非官方属性、群文化和讨论方式。

### 5. 核心规则速览

介绍 AI 审判、管理员执行、警告系统、讨论秩序等核心机制。

### 6. 群规全文

展示 GitHub Raw 动态读取的群规全文。

### 7. 释规案例与变更记录

展示规则如何被解释、执行和迭代。

### 8. 荣誉殿堂

荣誉殿堂应继续保留，但应放在访问者理解群价值之后。该模块用于说明维护成本、感谢发电群友、展示爱发电权益说明图。

### 9. 公开入口

最后集中展示 GitHub 仓库、群规原文、释规案例库、变更记录、爱发电、收支明细、AI 参考和机器人功能说明。

## 不展示内容

1. 不展示入群方式、群二维码、邀请链接或联系人。
2. 不展示原始群聊记录全文。
3. 不展示真实发言人昵称。
4. 不展示可反向识别个人身份的细节。

## 验收标准

1. 首屏能让陌生访问者理解群聊定位和价值，而不是先看到赞助信息。
2. 首页靠前位置存在脱敏讨论现场模块。
3. 讨论现场模块不包含真实发言人昵称。
4. 荣誉殿堂位于规则介绍和讨论价值之后。
5. 仍然不展示任何入群方式。
6. 桌面端和移动端均无横向溢出。
