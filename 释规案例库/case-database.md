# Q1: 避免troll的适用规则

毛毛人问：@姚泽源 引用这个群规警告短裤是否合适？短裤针对文总发表言论“那你是针对我了，你自己说的top3，结果只警告我一个”，这个言论被证明是错的，发出警告是否属于扩大了“转发”内容的含义？以后群内群友自己任何非转发的主动发言（比如：你没精打采，肯定熬夜了。），如果被确认虚假，是否都可以使用此群规？请给出司法解释。（2026.03.25 12:13）

群主答：
1. 释法：「那你是针对我了，你自己说的top3，结果只警告我一个」这个言  论是自身发言，不属于转发, 不适用于这条群规：
【避免troll】
转发需保障信息的真实有效，若被他人证明为虚假内容，警告1次
2. 不避AI条款的适用规则
一般来说，如果发布的是文本，那么按照AI审核
  1. 如果是本群聊天记录，视为举证，忽略
  2. 如果是外群聊天记录/图片/视频，那么视为提升了管理成本，按【不避AI】进行审核

# Q3: 三法司会审的使用方案

howe问：三AI判定中，有一个AI判定是口头提醒的，个人认为应该统一就轻。群主释规一下？（2026.02.21）

毛毛补：若均判违规，视为终审裁定。若审判结果不一，以对裁定者最有利的AI为准。群管只可根据AI判定，在确认违规后发出警告并执行，不执行需给出理由。

追问：对啊，以对裁定者最有利的AI为准。
最有利判定是违规但口头提醒即可，只是AI汇总3AI判定成需要提醒了。
这个有不同理解，我之前都是以最轻为准。

群主答：如果只口头提醒，则目标不再是维护秩序，只是为了让群友了解判定规则，避免未来被真实判罚。所以由管理员自行决定是否口头提醒即可。

追问：姚总，你的意思是，这种情况，可以按AI判定的最轻口头提醒，也可以按AI汇总后的正式提醒，是吧？

群主答：是的，这些情况都属于「无需发送警告」的场景
由于不产生警告(真实影响)。那么管理员自由决策即可。

追问：1、这个是属于口头提醒和发出正式警告之间的判定，所以会产生是否要警告的问题。2、那AI罗列的表格和最终文字建议不一致，咋办？

群主答：1、以最终裁定为准吧。我们作为人类，不干涉 ai 的审判过程，只执行。
            2、以表格列为准，表格列认定违规则发警告。否则为口头提醒或者忽略
