# Q6: 关于审判的界定

howe问：@姚泽源 目前可以人人执法，还是仍然要AI判定后，管理员执行？（2026.01.22）

群主答：任何人可以审判，也可以口头警告

但发出警告涉及踢人，这个权力收拢到管理员以便追责。如果AI判定需要警告，但管理员不执行AI判罚的话，需要给出解释。

对于AI判定的正式警告，允许管理员在给出理由后进行降级/豁免，多个管理员意见不一时，以对被判定人最有利的版本为准并由对应管理员承担滥用职权的责任。

对管理员只考核其执法过程是否遵循群规。因此，降级操作属于管理员个人为其进行信用背书。若被群主自由心证判定管理员违规，可撤销其管理身份。

# Q7: 对于管理对于判定(是否违规、警告持续时长)不一致的场景

答：对于争议操作，按以下流程进行:
1. 若管理以个人信誉背书，则以最终发言为生效决议。
2. 若只是提出异议，则剩下2名管理员有异议可以直接在群里讨论，按未票从多逻辑，少数服从多数。平局后上升至群主裁决。

示例:
比如毛工认为警告维持7天，其余2人未反对，则未票从多，相当于3人一致赞同

howe工直接修改决定后，此时其余两人未表态，仍然是未票从多，按最新决定决定，视为3人一致赞同。
但如果此时毛工再次表态，认为应该维持原决定，则需要白鸟总表态，以多数为准。

此时3人一定有多数票，但如果白鸟总提出了第三个处理方案，相当于1：1：1，群主再进行干预。
